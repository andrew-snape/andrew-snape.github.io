I'm Andrew, and this is a coding blog about my homelab.

I used to maintain tooling for Mac fleet management — that work is done and
those repos are retired. These days my focus is a self-hosted NAS running a
Docker-based stack: the *arrs for media acquisition, Plex for playback,
Immich for photos, File Flows for automated file processing, and Homebridge
for tying smart-home devices into HomeKit (including my own
[homebridge-cgd-garage-door](https://github.com/andrew-snape/homebridge-cgd-garage-door)
plugin).

This site is where I write up how it's all put together.
